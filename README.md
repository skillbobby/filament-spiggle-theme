# Filament Spiggle Theme

A sleek, modern **TailAdmin-inspired theme** for Filament PHP applications (v3, v4, and v5 compatible). Features Professional  Font, periwinkle accents (`#465FFF`), extra-rounded card containers, and clean active navigation styling.

![Theme Preview](images/preview.png)

## Features
- **Superb Aesthetics**: Vibrant `#465FFF` accent color with clean `#F3F4F6` canvas contrast.
- **Modern Font**: Built-in integration with Google Font `Outfit`.
- **Extra-Rounded UI**: `rounded-2xl` cards, inputs, and widgets.
- **Custom Navigation**: High-visibility active nav pills and soft green badges.
- **Filament v3 / v4 / v5 Compatible**: Native support for current and latest Filament versions.

---

## Installation

### 1. Install via Composer
```bash
`composer require spiggle/filament-spiggle-theme`

That's it! The theme will automatically apply to all your Filament panels.
